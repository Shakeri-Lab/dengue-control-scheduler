See how a vector-control schedule changes the Aedes aegypti population and dengue transmission risk at your site, from one year of daily temperature.

Everything runs in this browser tab. Your files are not uploaded anywhere.

What this page does. It runs the fixed-schedule mode of the Aedes Control model: the same Python files as the desktop application, executed in your browser. The first visit downloads the Python runtime (about 35 MB); a run then takes roughly half a minute to a minute.

What it does not do. Searching for the best dates (Optimize mode) takes tens of minutes of compiled code and is only in the desktop application. Location lookup from the worldwide climate grids is also desktop-only; here you bring your own CSV.

Model and method: Vajdi, Cohnstaedt, Scoglio, Shakeri, Optimal Scheduling of Dengue Vector Control, arXiv:2605.12441. Source code: Shakeri-Lab/dengue-control-scheduler.
